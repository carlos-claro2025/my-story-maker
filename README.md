# 📱 my-story-maker

> **Editor de stories e collages** para Instagram, totalmente web‑based e pronto para uso.

## 🚀 Principais Funcionalidades

- **Criação de Stories** – Arraste e solte imagens, adicione textos, stickers e filtros em tempo real.
- **Editor de Collages** – Combine múltiplas fotos em layouts pré‑definidos ou personalizados.
- **Persistência local** – Salve projetos no IndexedDB e recupere‑os a qualquer momento.
- **Exportação** – Salve stories como imagens PNG ou exporte collages em formatos JPEG/PNG.
- **Interface responsiva** – Layout adaptável para desktop, tablet e celular.
- **Modo de Colaboração** – Compartilhe projetos via link e trabalhe em equipe.
- **Integração com APIs** – Suporte a chamadas externas (ex.: upload direto para Instagram via API).
- **UI moderna** – Design limpo, com animações suaves e feedback visual (toast, modais).
- **Extensibilidade** – Estrutura modular em JavaScript, facilitando a adição de novos filtros ou templates.

## 📦 Instalação Local

```bash
# Clone o repositório
git clone https://github.com/carlos-claro2025/my-story-maker.git
cd my-story-maker

# Instale dependências (se houver)
# npm install

# Inicie o servidor de desenvolvimento
# npm run dev
```

Acesse `http://localhost:8765/` para testar.
